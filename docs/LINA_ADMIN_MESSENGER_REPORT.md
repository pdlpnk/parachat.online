# LINA Stage 4 — Admin Messenger

2026-09-10. Реализация и проверки только в Chat WEB. Production не подключался и не изменялся.

1. **Реализовано.** Отдельный Admin Messenger: список/история, Active/Archive, поиск, unread, OPERATOR send, read markers, tags, mobile back. Player identity и permanent Conversation сохранены.
2. **Routes.** `/admin/login`, `/admin`; `/api/admin/login` POST, `/logout` POST, `/conversations` GET, `/conversations/:id/messages` GET/POST, `/read` POST, `/state` POST, `/tags` POST; `/api/admin/tags` GET/POST и `/api/admin/tags/:id` PATCH/DELETE. Prefix для сокращённых путей — `/api/admin/conversations/:id` или `/api/admin`, соответственно. Публичного signup нет. Next catchall маршрутизирует только перечисленные операции.
3. **Миграции.** `20260910000000_admin_messenger`: одна ограниченная строка DB login throttle, индекс Message(adminAuthorId,createdAt). `20260910010000_admin_unicode`: deterministic ICU collation и Unicode-normalized tag constraint; миграция атомарная, конфликт старых тегов приводит к ошибке без удаления данных. Требуется PostgreSQL с ICU. Existing Admin/AdminSession/AdminConversationRead/AdminTag/ClientTag переиспользованы. Старые миграции не менялись.
4. **Auth.** scrypt N=32768,r=8,p=3, random salt 16 bytes, derived key 64 bytes. Opaque random 256-bit session; DB хранит domain-separated SHA-256 hash. Prod `__Host-lina_admin`, Secure/HttpOnly/Lax/Path=/; dev отдельный lina_admin. Idle 30 минут, absolute 12 часов; disable/revoke/expiry проверяются каждым API. GET polling не продлевает idle, успешные read/send/mutations продлевают до absolute bound. Logout отзывает строку. Все Admin равноправны в MVP.
5. **Первый Admin.** `pnpm admin:create` с настроенным нужным DATABASE_URL. CLI показывает host/db без пароля, спрашивает ASCII email, display name, дважды скрытый пароль 12–128 символов. Только TTY, пароль не принимается через argv/env/pipe; уникальность email, plaintext не сохраняется. Интерактивный CLI локально проверен: пароль не появился в выводе.
6. **Active/Archive.** Active = firstUserMessageAt nonnull AND closedAt null; Archive — дополнение. Welcome/SYSTEM не активирует. USER auto-reopen сохранён. OPERATOR в Archive разрешён, не открывает автоматически. Read/tag/archive/retry не меняют lastMessageAt.
7. **Read/unread.** Только USER после курсора конкретного Admin. Курсор ссылается на существующее сообщение этого Conversation, monotonic upsert. Два Admin независимы; OPERATOR/SYSTEM не увеличивают admin unread. При открытии последняя страница прокручивается вниз и подтверждается; чтение выше сохраняет позицию.
8. **Tags/search.** Unicode NFC, whitespace normalization, unique name с ICU lower, create/rename/delete/attach multiple/remove; cap 200 тегов, длина 60. Игнорирование регистра имени не зависит от locale C; LI case normalization. Debounce 220 ms. Tags никогда не выходят в Player DTO. Удалённый filter сбрасывается на Все теги. Один SQL списка: фильтры до LIMIT 50, last real message DESC NULLS LAST, стабильный tie-break id, без N+1. Имя — literal substring scan; LI использует unique index. На большой базе потребуется измерение EXPLAIN и отдельная оптимизация поиска/общих unread, а не преждевременный индекс без измерений.
9. **Polling/scroll.** Список 10 sec, история 5 sec через Stage 3 polling primitive; hidden pause, no overlap, AbortController/late guards. История initial latest 100, delta <=100 + hasMore, merge by sequence. Send response не двигает poll cursor. Near bottom 80px, иначе indicator без прыжка; Enter/Shift+Enter/IME, loading/retry same text+key/focus. Черновик и retry живут в выбранном диалоге, не сохраняются после закрытия/перезагрузки. Загрузка истории старше начальных 100 сообщений не добавлена (сохранён MVP pattern Stage 3).
10. **Security.** Server-owned OPERATOR/admin author, text Unicode 1–5000, UUIDv4 idempotency; same payload replay, altered payload 409; sequence/lastMessageAt атомарны. Admin login DB ceiling 20/min глобально, sends 60/min на Admin между процессами; replay не расходует новый send. В Nginx example отдельный login IP zone 5/min + burst5. Global login ceiling может временно блокировать все входы при атаке; пер-IP nginx защита рекомендуется. Exact Origin, strict fields, JSON byte limits 2KiB/default, 64KiB/send, 512B/read-state-attach, safe DTO/errors/no-store. Client/admin credentials не взаимозаменяемы. No secrets in committed env examples. `/dev/messenger` production 404.
11. **Browser QA.** На локальном production standalone: login, desktop list/detail, same-name LI000097/98, lower-case Cyrillic и LI search, unread снят только после чтения, многострочный reply через Enter/Shift+Enter получен Player polling; tags create/attach/filter/rename/delete/filter reset; Archive/reopen; mobile list/detail/back. Проверены 320×568,360×640,390×844,414×736,430×932,568×320,844×390,1100×420: document scrollWidth=viewport width, composer внутри viewport, input16px. Длинный ~4600 Unicode текст: последний bubble доступен над composer; при scroll вверх новый USER показывает indicator, scrollTop остаётся0; indicator возвращает вниз (1px от конца). Реальная iOS-клавиатура/IME hardware не эмулировалась; guard и safe-area реализованы, нужна обычная ручная проверка на устройстве перед rollout.
12. **Tests.** 26 unit; 59 DB (19 Admin +40 прежних); 52 Admin production HTTP ответа; 104 Player messages HTTP ответа; прежний player identity HTTP smoke. Все PASS. Unicode регрессия проверена на PostgreSQL LC_CTYPE=C. Две независимые DB pools проверяют concurrent send/retry/read и limits; insert failure rollback. Финальная новая DB применяет все 5 миграций с нуля; изменения Stage 4 также применялись к локальной Stage 3 DB.
13. **Gates.** ESLint zero warnings, Next typegen + tsc --noEmit, Prisma validate/generate, Next production build + standalone assets PASS. Nginx/PM2 config execution и реальный Ubuntu runtime здесь не тестировались.
